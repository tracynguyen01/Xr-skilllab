Architecture

How It Works

Scoring is rule-based and transparent: every point comes from a fixed rule you can read, so two learners who make the same decisions get the same score, and every result can be audited. The coaching layer explains those rules in plain language; it never decides the score.

Why It Matters

Training that people actually do.

Practice in context

Decisions in a realistic scene, not abstract quizzes. Learners notice hazards the way they are drawn in the scene.

Measurable

Every decision is captured as auditable assessment data, so progress can be reviewed rather than assumed.

Accessible anywhere

Browser-based, with a full keyboard 2D mode and no special hardware, so the same exercise reaches every learner.

Instructions

  • Find the four hazards and choose the best response for each. Each hazard can be answered once per attempt.
  • 3D: drag to look around, scroll or pinch to zoom, arrow keys rotate. Click or tap anything to inspect it.
  • 2D: Tab between numbered objects and press Enter to inspect. Everything is keyboard operable.
  • Inspecting a safe object costs nothing. Hints don't change your score. Time is recorded for information only.
  • Finish Assessment whenever you're ready. Unanswered hazards are marked Missed.
